# คิดเลขพอดี

เครื่องคิดเลขแบบพิมพ์ทั้งบรรทัดบนมือถือ (PWA ใช้ออฟไลน์ได้)

- แตะบรรทัดเก่าเพื่อแก้ แล้วบรรทัดอื่นที่อ้างถึงคำนวณใหม่ให้เอง
- ตั้งตัวแปรภาษาไทยได้ เช่น `ค่าห้อง = 3500` และใช้ `ans` แทนผลบรรทัดก่อน
- % แบบที่คนใช้จริง: `1250 + 7%`, `ans − 10%`
- แสดงคำอ่านเงินเป็นภาษาไทย (บาท/สตางค์)
- เก็บการคำนวณไว้ในเครื่อง

## โหมดอื่น (แท็บด้านบน)

- **หารบิล** — service / VAT / ทิป / ส่วนลด หารต่อคน พร้อม QR พร้อมเพย์ยอดคนละ
- **วันที่** — พ.ศ.↔ค.ศ., นับวันระหว่างสองวัน (+วันทำงาน), บวก/ลบวัน, อายุ
- **เงิน** — ผ่อนรายเดือน (ลดต้นลดดอก / flat), เงินออมทบต้น, ต้นทุนต่อแก้ว
- **เทรด** — lot size จาก % ความเสี่ยง (XAUUSD, FX, BTC) พร้อม R:R
- **แปลงหน่วย** — ความยาว น้ำหนัก ที่ดิน (ไร่-งาน-วา) ปริมาตร อุณหภูมิ และสกุลเงินเรตจริง (เก็บไว้ใช้ออฟไลน์)
- **เมนู ⋯** — แชร์เป็นรูป, ธีมมืด/สว่าง, โหมดมือเดียว
