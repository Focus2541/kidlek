# คิดเลขพอดี

เครื่องคิดเลขแบบพิมพ์ทั้งบรรทัดบนมือถือ (PWA ใช้ออฟไลน์ได้)

- แตะบรรทัดเก่าเพื่อแก้ แล้วบรรทัดอื่นที่อ้างถึงคำนวณใหม่ให้เอง
- ตั้งตัวแปรภาษาไทยได้ เช่น `ค่าห้อง = 3500` และใช้ `ans` แทนผลบรรทัดก่อน
- % แบบที่คนใช้จริง: `1250 + 7%`, `ans − 10%`
- แสดงคำอ่านเงินเป็นภาษาไทย (บาท/สตางค์)
- เก็บการคำนวณไว้ในเครื่อง
