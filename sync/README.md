# ตั้งค่าซิงก์ คิดเลขพอดี (ครั้งเดียว ~5 นาที)

ข้อมูลเก็บในไฟล์ `kidlek-sync.json` บน Google Drive ของคุณเอง ไม่ผ่านเซิร์ฟเวอร์ใคร

1. เปิด **script.google.com** → **New project** ตั้งชื่อ `kidlek-sync`
2. ลบโค้ดเดิม แล้ววางโค้ดจาก [`Code.gs`](Code.gs)
3. แก้บรรทัด `const SYNC_KEY = '...'` เป็นรหัสของคุณเอง (ยาว ๆ เดายาก เช่น `focus-kidlek-7Qx29`)
4. เลือกฟังก์ชัน **setup** แล้วกด **Run** → อนุญาตสิทธิ์ (Advanced → Go to kidlek-sync → Allow)
5. **Deploy → New deployment** → เลือกประเภท **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy แล้วคัดลอก **Web app URL** (ลงท้าย `/exec`)
6. ในแอปคิดเลขพอดี กด **⋯ → 🔄 ซิงก์ / ส่งไปเครื่องอื่น** ใส่ลิงก์ `/exec` และรหัสเดียวกัน → **บันทึกและซิงก์ตอนนี้**
7. ทำข้อ 6 ซ้ำในอีกเครื่อง (ลิงก์และรหัสเดียวกัน)

## ทำงานยังไง
- ซิงก์เองตอนเปิดแอป สลับกลับมาที่แอป และทุก ~15 วินาทีหลังแก้
- รวมกันทีละแผ่น: แผ่นไหนแก้ล่าสุดในเครื่องไหน ใช้อันนั้น · ลบแผ่นที่เครื่องหนึ่ง อีกเครื่องก็หาย
- ไม่มีเน็ตก็ใช้ได้ตามปกติ จะซิงก์เมื่อกลับมาออนไลน์
- ถ้าแก้ **แผ่นเดียวกัน** ในสองเครื่องพร้อมกันก่อนซิงก์ อันที่แก้ทีหลังจะทับอันก่อน

ถ้าแก้ `Code.gs` ภายหลัง ต้อง **Deploy → Manage deployments → Edit → New version** ลิงก์เดิมจะใช้ต่อได้
